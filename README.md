# Exercícios: Funções e Entrada de Dados com `prompt()`

Repositório com a resolução dos 10 exercícios práticos sobre funções em JavaScript utilizando `prompt()` para entrada de dados e `console.log()` para exibição dos resultados.

## Lista de Exercícios

| # | Exercício | Função | Arquivo |

| 1 | Saudação | `saudacao(nome)` | [`exercicios/ex01-saudacao.js`](exercicios/ex01-saudacao.js) |
| 2 | O dobro | `dobro(numero)` | [`exercicios/ex02-dobro.js`](exercicios/ex02-dobro.js) |
| 3 | Soma de dois números | `soma(a, b)` | [`exercicios/ex03-soma.js`](exercicios/ex03-soma.js) |
| 4 | Par ou ímpar | `ehPar(numero)` | [`exercicios/ex04-par-ou-impar.js`](exercicios/ex04-par-ou-impar.js) |
| 5 | Maior de dois | `maiorDeDois(a, b)` | [`exercicios/ex05-maior-de-dois.js`](exercicios/ex05-maior-de-dois.js) |
| 6 | Média de notas | `calcularMedia(n1, n2, n3)` | [`exercicios/ex06-media-notas.js`](exercicios/ex06-media-notas.js) |
| 7 | Área do retângulo | `areaRetangulo(base, altura)` | [`exercicios/ex07-area-retangulo.js`](exercicios/ex07-area-retangulo.js) |

## Como executar

1. Abra o arquivo `index.html` diretamente no navegador.
2. (Opcional) Pressione `F12` e abra a aba **Console** para visualizar os logs nativos.
3. Clique em **Executar** no exercício desejado e preencha os valores solicitados no `prompt()`.
